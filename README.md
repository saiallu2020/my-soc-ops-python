# 🎯 Soc Ops — Social Bingo

> **Break the ice, make real connections, and turn any mixer into a game.**

Soc Ops is a social bingo web app for in-person events. Players find people who match prompts, mark their board, and race to get 5 in a row.

## ✨ Why it’s fun

- 🎲 **Fresh boards every round** with randomized square placement
- 💾 **Session-based progress** so refreshes don’t wipe the game
- ✅ **Built-in bingo detection** for rows, columns, and diagonals
- 📱 **Mobile-friendly UX** for conferences and team socials
- ⚡ **Fast local setup** for workshops and demos

## 🚀 Quick start

```bash
uv sync
uv run soc-ops
```

Then open `http://localhost:8000`.

### Validate locally

```bash
uv run ruff check .
uv run pytest
```
